Stand 14.10.2026. Zurück zur [Übersicht](README.md).

## Wörter aus der Zusammenarbeit

| Begriff | Bedeutung |
|---|---|
| **Mockup** | Ein Bild, wie eine Seite aussehen soll, immer für Computer (1440 px breit) und Handy (390 px), nur im hellen Modus. Mit fiktiven Daten. |
| **Freigabe** | Noah bestätigt Bilder mit «<Kürzel> freigegeben». Erst danach wird gebaut. «ohne Bilder» erlaubt ausnahmsweise das Bauen ohne Mockups. |
| **a/b-Frage** | Eine Frage mit zwei ausgeschriebenen Möglichkeiten. Noah antwortet kurz, etwa «1a 2b 3a». Höchstens 5 pro Runde. |
| **Thread** | Ein Gesprächsfaden im Claude-Projekt zu einem Thema, mit einer eigenen Claude-Sitzung. |
| **Koordination** | Die Claude-Sitzung im Projekt-Chat, die Aufgaben an Threads verteilt und Überschneidungen prüft. |
| **PR (Pull Request)** | Ein Änderungsvorschlag auf GitHub. Noah merged ihn selbst («Merge pull request» → «Confirm merge»), dann geht er online. |
| **CI, grün** | Die automatischen Tests auf GitHub. «Grün» heisst: alle bestanden. |
| **Vorschau (Vercel)** | Jeder PR bekommt eine eigene Test-Adresse mit leerem Speicher. Echte Daten bleiben unberührt; ein Backup lässt sich dort laden. |
| **Tagespaket** | Alle grünen, freigegebenen PRs eines Tages, abends zu einem Release mit einer Versionsnummer und einem Link gebündelt. |
| **Gesamttest** | Browser-Test aller Seiten und Abläufe mit fiktiven Daten. Läuft auf GitHub. |
| **Mein Überblick** | Noahs private Übersichtsseite mit allen Ideen, ihrem Stand und den Regeln. |
| **Offene Mockups** | Private Galerie-Seiten mit allen Bildrunden. Seite 1 und 2 sind voll (Dateigrenze), neue Runden bekommen eigene Seiten. |
| **Werkstatt** | Klickbarer Prototyp der App, in dem Noah Notizen direkt in die Bilder setzt. |
| **Release-Analyse** | Prüfung aller Releases vom 14.10. auf verlorene oder versteckte Funktionen. |
| **«Was fällt weg oder rutscht tiefer»** | Pflichtabschnitt in jedem PR seit 14.10. |
| **Selbst entschieden** | Abschnitt im PR für kleine Entscheide, die Claude ohne Rückfrage traf. |
| **Umnummerieren** | Rückt `main` weiter, bekommt ein offener PR die nächste freie Versionsnummer. Darum fehlen manche Nummern. |
| **GitHub-Stopp** | Noah kann alle Änderungen auf GitHub anhalten; nur er hebt den Stopp auf. |

## Wörter aus der App

| Begriff | Bedeutung |
|---|---|
| **Fünf Orte** | Die Hauptbereiche: Heute, Touren, Material, Velos, Aktiv; dazu «Ich» oben rechts. |
| **Heute** | Startseite mit Kacheln (Kachel-Wand), Tour-Karte, Vorschlägen. |
| **Baustein** | Eine Gruppe von Teilen, die zusammen auf eine Tour kommen (zum Beispiel Reparatur, Regen, Übernachtung). |
| **Vorlage** | Eine gespeicherte Ausgangsliste für eine Tourart. |
| **Rahmenbedingungen** | Der erste Schritt einer neuen Tour: Sportart, Wetter, Event. |
| **Schnellstart** | Ein Klick auf Heute plant eine Tour für heute. |
| **Rückblick** | Auswertung nach einer Tour: was gebraucht, was nicht, was gelernt. |
| **Im Flow / Aktiv** | Bereich für Gewohnheiten, Sport, Meditation, Meilensteine und Challenges. |
| **Challenge** | Ein Vorschlag, den man als Ziel annimmt; er zählt selbst mit und wird bei Erfolg ein Meilenstein. |
| **Wi gaht's? / Deine Abfragen** | Eigene Fragen an sich selbst mit eigenem Takt, ersetzt den Tages-Check (ab 0.133.0). |
| **Spielwiese** | Ein Übungsmodus mit Beispieldaten, der die echten Daten nicht berührt. |
| **KI-Helfer** | Optionale KI-Unterstützung (kostet), ab Werk aus. |
| **Kleine Apps** | Meditation, Packliste und Velopflege als eigene Symbole auf dem Startbildschirm, mit denselben Daten. |
| **Dexie, Datenbank-Version** | Der Speicher im Browser. Neue Tabellen brauchen eine höhere Versionsnummer. |
