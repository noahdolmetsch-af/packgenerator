# Challenge zählt Meditation von selbst

26.11.2026 · Auftrag: Noah «1-5a» und «ja» vom 24.11.2026 (Schritt 2); Umsetzung im Thread «Challenges nach Gelegenheit bauen»

- Eine Challenge in Minuten kann zur Meditation gehören (Feld `link`); die Sitzungen zählen dann von selbst zum Tagesziel.
- Gespeichert wird nur die Verknüpfung. Die Minuten aus den Sitzungen werden beim Lesen gerechnet (`withAuto`), nie in `hand` geschrieben: nichts zählt doppelt, ein gelöschtes Mal wirkt sofort.
- Die Challenge «30 Tage Meditation» startet verknüpft; das Kästchen im Fenster schaltet es aus. Bestehende Challenges bleiben unverändert, bis jemand das Kästchen anhakt.
