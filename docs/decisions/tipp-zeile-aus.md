# Tipp-Zeile unter den Seitentiteln aus

22.11.2026 · Auftrag: Noah «3b» (21.11.2026, «Hinweise nur noch auf Heute») und «1a 2a» (22.11.2026, Thread «Neue Ordnung»)

- Die Tipp-Zeile «Gut zu wissen» unter den Seitentiteln ist standardmässig aus; sie lässt sich in Ich › Eigene Werte einschalten (Noah «1a»; verworfen: sie bleibt).
- Vorschläge und Warnungen im Inhalt («Freie Zeit und gutes Wetter», «Diese Woche ist deutlich mehr …», «Eine leichtere Woche würde passen», «Verpasst? Verschieben») bleiben, weil sie bei einer Entscheidung helfen (Noah «2a»; verworfen: nur auf Heute, hinter «Hinweise (3)»).
