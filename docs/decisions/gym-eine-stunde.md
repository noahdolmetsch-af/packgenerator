# Gym zählt eine Stunde

22.11.2026 · Auftrag: Noah «1a 2a 3 gym normalfall 1h sonst a 4b 5a» (Thread «Alle Sportarten und Erholung»)

- Gym-Normalfall: 1 Stunde (ersetzt die 20 Minuten für eGym vom 21.11.2026). Wo die Uhr eine echte Dauer kennt, steht ein Tipp «Von der Uhr übernehmen», nie still.
- Ein eigener Wert bleibt vor dem Standard; die Laufband-Regel (20 Minuten) bleibt vor Gym.
