# Gruss-Gesichter als Skalenfrage

22.11.2026 · Auftrag: Noah «a» (Thread «Alle Sportarten und Erholung», Schritt C/F2)

- Ein Gesicht im Gruss ist eine Antwort der Skalenfrage `spass.stimmung` (1–10, Müed 1, Gaht so 3, Okay 6, Guet 8, Super 10); der Wochenrückblick liest so eine Stimmung. Die älteren `hallo.gaht` bleiben gespeichert und werden gelesen, nichts wird umgeschrieben.
- Verworfen: die alten Antworten in `spass.stimmung` umzuschreiben (Datenänderung ohne Not; die Zahl wäre geschätzt).
