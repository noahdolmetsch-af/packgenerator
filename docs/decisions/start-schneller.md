# Start schneller: zwei Zahlen

23.11.2026 · Auftrag: Noah «Mach die App 5 mal schneller» (Thread «App fünfmal schneller machen»)

- Die Geschwindigkeit des Starts wird mit zwei Zahlen gemessen und berichtet: **Start** (erstes Bild, jetzt das Gerüst aus `index.html`) und **Inhalt da** (grösster Inhalt von Heute, Tempo-Messer). Grund: Ein Gerüst macht «Start» kurz, ohne dass der echte Inhalt früher da ist; wer nur eine der Zahlen nennt, täuscht. Jeder Tempo-PR nennt beide, vorher und nachher, gemessen mit derselben Handy-Ansicht und 4× gebremstem Prozessor.
- «import-wrapper.js» im Tempo-Messer ist die Datenbank-Bibliothek (Dexie), nicht ein fremdes Programm. Die Zeit zählt alles, was aus einer Datenbank-Antwort heraus läuft (auch das Zeichnen von Heute).
