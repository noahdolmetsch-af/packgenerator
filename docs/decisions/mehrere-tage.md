# Mehrere Tage in einem Rutsch

21.11.2026 · Auftrag: Noah «bitte hiermit fortfahren» (Thread «Training erfassen vereinfachen»)

- Das Abhak-Fenster kann für mehrere Tage auf einmal abhaken (Knopf «Mehrere Tage in einem Rutsch»): ein Eintrag pro Tag, gleiche Dauer und Uhrzeit, ein Rückgängig für alle. Verworfen: eine eigene Dauer pro Tag (das Fenster bliebe nicht klein).
