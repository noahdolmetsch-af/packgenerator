# Dauer nachtragen

21.11.2026 · Auftrag: Noah «1 a dann b dann alle anderen 2a 3a 4a 5a» (Thread «Sportjahr», S12, Entscheid 2b)

- Haken ohne Minuten lassen sich mit einem Tipp nachtragen (15, 30, 45, 60 Min oder eine eigene Zahl); danach zählt die Zeit als gemessen. Verworfen: die Zeit immer nur schätzen (üblich) und nie nachtragen.
- Tourtage ohne Strava-Zeit und ohne Minuten-Haken bekommen keine Schätzung; sie kommen in dieselbe Liste («Tour am …, wie lange?»), siehe den PR «Dauer nachtragen: Tourtage».
