# Touren: Rennen als Reiter (Noah 24.11.2026, Sitemap K3, K6, K7-Teil)

- «Rennen» wird dritter Reiter von Touren; «Vorlagen» geht am Handy unter «Mehr». Der Link «Rennen ›» auf der Übersicht bleibt.
- Die Werkzeuge einer Tour (Verpflegung, Tour-Pfad, Weg zum Ziel, Touren nebeneinander, Stopps, Quiz, Checks pro Tourart) stehen in einer geschlossenen Gruppe unter «Mehr zu dieser Tour», nie über der Packliste.
- Auf Touren › Übersicht steht neben «Rennen ›» ein Link «Unterwegs ›», solange eine Tour geplant ist.
