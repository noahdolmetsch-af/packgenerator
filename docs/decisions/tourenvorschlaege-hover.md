# Tourenvorschläge: Zahlen beim Hovern

23.11.2026 · Auftrag: Noah «mouseover soll gleich wichtigste daten wie km, zeit und höhenmeter zeigen auf der karte»

- **Am Handy zeigt der erste Tipp die Karte, der zweite öffnet die Tour** (es gibt dort kein Hovern; verworfen: jeder Tipp öffnet sofort, dann sieht man die Zahlen nie).
- Die Zeit steht in **deinem Tempo** (wie in der Liste), nicht in einem Standardtempo.
