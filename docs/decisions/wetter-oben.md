# Wetter oben auf Heute

23.11.2026 · Auftrag: Noah «b» (Thread «Prototyp»)

- Alle Wetter-Infos bleiben auf Heute zuoberst und offen (Noah «zwingend»); sie nehmen etwa ein Fünftel der Bildschirmhöhe ein, der gewonnene Platz geht an neue Karten (verworfen: Wetter in ein Klapp-Feld oder nur ein Symbol).
- Wahl «b»: eine Karte (Jetzt links, Höhenleiter mit Schneegrenze rechts, Nebel/Nacht/See darunter) plus neue Karten «Wetter der Woche (bester Tag zum Fahren)», «Nach dem Regen: Kette ölen» und «Fahrfenster». Die neuen Karten kommen als eigener PR.
