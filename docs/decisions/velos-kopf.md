# Velos: Kopf in einer Zeile, ein ruhiger Knopf pro Karte

23.11.2026 · Noah «ja» (Antwort auf den Vorschlag des Koordinators, Thread «App an Mein-Tag-Design angleichen»)

- Auf jeder Velo-Karte ist «Werkstattbesuch erfassen» ein ruhiger Knopf; verworfen: ein grüner Knopf pro Karte.
- «Gehört zu …» und «Was du hier tun kannst» werden zu einer kleinen, aufklappbaren Zeile; verworfen: zwei Zeilen über und unter dem Titel.
- Nur Aussehen, nichts verschwindet.
