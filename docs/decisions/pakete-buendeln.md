# Kleine Pakete desselben Threads dürfen in einen PR

27.11.2026 · Auftrag: Noah «a» 27.11.2026 17:38, Antwort auf «3. Kleine Pakete desselben Threads: a) ★ dürfen zusammen in einen PR, zum Beispiel die 3 Lichter-Teile · b) bleiben einzeln» (Thread «Regeln und Anweisungen auf neuen Stand bringen»)

- **Kleine, freigegebene Pakete desselben Threads dürfen zusammen in einen PR**, zum Beispiel die drei Lichter-Teile. Das erweitert «kleine Änderungen derselben Seite gebündelt» (Block 4).
- **Einzeln bleiben** Datenänderungen (Dexie, Backup, Sync, `api/`) und Test-Fixes (so meldet es der Bündler; die Zeile stand schon vorher in Block 4).
- Die Regel vom 25.11.2026 20:08 «jeden Teil eines Bereichs als eigenen PR» gilt nur noch für grössere Teile; kleine Teile desselben Threads dürfen zusammen (siehe «Selbst entschieden» in der Release-Datei).
- Die alte Fassung steht in `docs/regeln-archiv.md`.
