# Körper-Banner auf Heute

23.11.2026 · Auftrag: Noah «1-4a» (Thread «Körper-Banner auf Heute bauen»)

- Position: direkt unter dem Gruss, weiterhin verschiebbar und ausblendbar (1a; verworfen: bleibt, wo die Kachel steht).
- Handy: 4 + 3 Felder auf zwei Zeilen (2a; verworfen: eine Zeile zum Wischen).
- Die drei Zusatz-Hinweise (Ruhepuls über Mittel, Wochenlast, Tageslicht-Rest): eine ruhige Zeile, nur wenn etwas auffällt (3a; verworfen: immer alle drei, nur im Fenster).
- «Geholt»-Zeit beim Ruhepuls und als eine Zeile für alle (4a; verworfen: nur die eine Zeile).
- Der Banner baut auf «Dein Körper heute» auf, es gibt keine zweite Kachel; der Schlafwert (Score) bleibt im «Details»-Fenster, nichts fällt weg.
