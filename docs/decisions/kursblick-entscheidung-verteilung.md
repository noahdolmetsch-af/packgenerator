# Kursblick «Gesamtbild»: Gruppen, Ziele, Spielraum und Werte von Hand

23.11.2026 · Auftrag: Noah «einzelne neue Aktien … Obligationen. ETFs», «Krypto, Rohstoffe, Immobilien, Sparkonto», «ok freigabe» (Thread «Kursblick»)

- **Nur echte Depots zählen** (angenommene Antwort ★, Noah kann ändern): Übungsdepots fliessen nie in das Gesamtbild, die Ziele oder die Regeln.
- **Spielraum in Punkten** (Standard 5, 0 bis 50): eine kleine Abweichung ist kein Urteil; erst darüber wird eine Gruppe markiert.
- **Ziele müssen nicht 100 ergeben**: die Franken pro Gruppe werden aus dem eigenen Ziel gerechnet; die Summe wird nur gezeigt.
- **Gruppen** gehören zu `GROUP_PLACES`: umbenennen, hinzufügen, verschieben, löschen; beim Löschen gehen Titel und Werte in eine andere Gruppe oder bleiben ohne Gruppe. Nie wird etwas mit einer Gruppe gelöscht.
- **Werte von Hand** (Sparkonto, 3a, Wohnung, Münzen) werden nicht verfolgt: Kursblick rechnet sie nur ein, die Person pflegt sie.
- **Regel gegen Ziel:** ein Widerspruch wird nur gesagt, nie aufgelöst; die Person entscheidet.
- Verworfen: automatisch erraten, in welche Gruppe ein Titel gehört (ein Symbol sagt es nicht verlässlich); die Person ordnet zu, bis dahin steht der Titel unter «Noch nicht eingeordnet».
