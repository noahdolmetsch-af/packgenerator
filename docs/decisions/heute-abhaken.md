# «Abhaken» als Chip auf Heute

22.11.2026 · Auftrag: Noah («ja» auf «direkter Abhaken-Knopf auf Heute»), Thread «Training erfassen vereinfachen»

- Seit V4a (Aktiv unter Woche › Training) war «Heute abhaken» drei Tipps tief. Ein Chip «Abhaken» unter dem Gruss auf Heute öffnet `#/flow` mit einem Tipp.
- Es ist ein Chip der bestehenden Liste «Chips unter dem Gruss» (`goals.js`): ausschaltbar und verschiebbar wie die anderen, an, wenn man nichts gewählt hat. Bei einem Gerät mit gespeicherter Auswahl erscheint er einmal an seinem Platz, an.
- Keine neue Seite, keine Datenänderung (die gespeicherte Auswahl `homeGoals` kennt jeden Chip, der später kommt).
