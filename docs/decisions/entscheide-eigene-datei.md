# Entscheide: eine Datei pro PR

21.11.2026 · Auftrag: Noah «1a 2a» (Zusammenarbeit)

- Jeder PR legt seine Entscheide in `docs/decisions/<name>.md` ab (gleicher Name wie in `docs/releases/`), nicht mehr am Ende von `docs/decisions.md`. Grund: Alle PRs hängten an dieselbe Stelle an und bekamen ständig Konflikte (jeder Konflikt heisst eine neue Prüfung von ca. 50 Minuten). Verworfen («b»): alles bleibt in einer Datei.
- Höchstens 5 PRs gleichzeitig in der Prüfung (Noah «1a», gleiche Antwort); der Bündler sagt, wann ein PR starten darf.
