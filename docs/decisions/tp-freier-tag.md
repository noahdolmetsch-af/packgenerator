# Recovery Day hält den Tag frei

22.11.2026 · Auftrag: Noah «Recovery Day ja» (Thread «TrainingPeaks ins Wochen-Soll einrechnen»)

- Ein Eintrag aus TrainingPeaks ohne Dauer, der «Recovery Day», «Rest day», «Ruhetag» o. ä. heisst, hält seinen Tag im Wochenplan frei: keine freie Einheit des Plans auf diesem Tag. Feste Einheiten bleiben.
- Er hat keine Stunden und ist keine Einheit (verworfen: eine Dauer erfinden, etwa 3 Std Ruheblock; das Leseprinzip «nie geraten» bleibt).
- Gespeichert als Tage im bestehenden Eintrag `training.plan` (`rest`), nicht als neuer Eintrag und nicht in den Geräte-Einstellungen: so sehen Handy und Computer dieselbe Woche.
