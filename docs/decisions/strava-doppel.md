# Strava-Fahrten zählen einmal

22.11.2026 · Auftrag: Noah «Warteliste Strava-Doppel», «a», «freigabe» (Thread «Sync»)

- Ein Strava-Eintrag im Fahrten-Buch hat als Schlüssel die Strava-Nummer der Fahrt, damit zwei Geräte nie zwei Einträge für dieselbe Fahrt machen.
- Die vorhandenen Doppel (7 Fahrten, 63 km zu viel im Backup vom 21.11.) räumt Noah selbst per Tipp auf «Aufräumen?» auf (Variante a); die App fasst Daten nie ohne seinen Tipp an.
- Einzelfreigabe von Noah am 22.11.2026 («freigabe»). Vorher macht die App eine Kopie der Daten, die zweiten Einträge werden ausgelassen (nicht gelöscht) und lassen sich zurückholen.
