# Dazu nötig: Begleitteile auf der Packliste

23.11.2026 · Auftrag: Noah «G1 G2 G3» (Thread «Packen leichter und besser machen»)

- Ein Teil kann Begleitteile nennen (Feld `withIds` am Teil, nur eine Liste von Teil-Nummern). Fehlt auf einer Packliste ein Begleitteil, sagt es die Karte «Bereit zur Abfahrt?» in einer Zeile; nichts wird von selbst hinzugefügt (Selbst entschieden: die App ist ein Vorschlag).
- Die App lernt Paare aus abgeschlossenen Touren, aber nur streng: mindestens 3 Touren mit dem ersten Teil, das zweite auf mindestens 90 % davon dabei und auf höchstens 20 % der anderen Touren seiner, beide Teile auf höchstens der Hälfte aller Touren, höchstens 3 Vorschläge je Liste. Verworfen: jede Gemeinsamkeit melden, das gäbe Lärm (auf Noahs Sicherungskopie 26 von 30 Touren mit Vorschlägen).
- Ein Begleitteil, das auf der Liste von Hand oder wegen des Wetters weggenommen wurde, oder das «Diesmal nicht» bekam, wird für diese Tour nicht mehr vorgeschlagen.
