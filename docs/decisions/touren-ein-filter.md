# Ein Filter auf Touren

- 26.11.2026, Noah «Ja» (18:07) auf die offene Frage 1 aus «Touren-Seite klarer» («die zwei Filter werden einer»), dann Wahl «a» (23:25): Feld und Knöpfe Jahr, Velo, Art, Distanz oben filtern die Liste «Meine Touren» selbst; die Box «Liste filtern» fällt weg, der Rest steht hinter «Mehr Filter».
- Ersetzt: die eigene Trefferliste von «Suche am Ort» auf Touren (Noah 22.11.2026 «2a», «3b»: vier Knöpfe und Summe); die Knöpfe bleiben, sie filtern jetzt die Liste.
- Zeitraum (12 Monate, Jahr, Alle) und Status (Alle, Abgeschlossen, Bewertet) bleiben als Umschalter über der Liste.
