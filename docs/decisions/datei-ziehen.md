# Datei auf das Fenster ziehen

23.11.2026 · Auftrag: Noah «3a» (Thread «Papierkorb, Tab-Titel und Ziehen bauen»)

- Eine Datei, die am Computer auf das Fenster der App fällt, geht durch dieselbe Weiche wie das Teilen am Handy (Fahrt, geplante Strecke, Backup, Foto/PDF), aber erst nach einem Blatt «Was soll mit dieser Datei geschehen?» mit Vorschlag; «Abbrechen» ist Standard, nichts wird ohne Wahl gespeichert, ein Backup geht nur durch «Backup prüfen».
- Nicht dabei: «Öffnen mit» (`file_handlers`), eigener PR nach Wunsch.
