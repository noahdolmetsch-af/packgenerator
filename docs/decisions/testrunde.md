# Testrunde: Karte auf Heute, Fenster mit Testschritten, «Klappt» / «Klappt nicht»

Noah 27.11.2026 (Thread «Alle Releases mit Testanleitung auflisten»), Antwort «1b 2a 3b 4b 5a».

Anlass: Noah sah, dass die Zeile «Neu: Eine Fahrt, ei… +3 Zeig mir» den Text abschneidet, und wollte, dass «Was ist neu» pro PR zeigt, was neu ist und wie man es testet (wie die Release-Liste).

| Frage | Antwort | Folge |
|---|---|---|
| 1 Form auf Heute | **b** Karte mit den neuesten 2 Neuheiten samt Testschritt | ersetzt die schmale Zeile vom 23.11. («Banner Was ist neu» «1-5a»); die Zeile war «Abhaken bleibt oben», die Karte steht weiter unter den Chips |
| 2 Fenster hinter «+N» | **a** pro Neuheit mit Testschritten, «Zeig mir», «Klappt», «Klappt nicht» (geloggt) | Fenster «Nach Update» mit Schalter «Nach Ort» |
| 3 Text der Zeile | **b** kurz mit «+2» | «+N weitere» (der Screenreader liest «und N weitere Dinge») |
| 4 Reihenfolge | **b** alles in einem grossen Paket | ein PR statt Umbruch-Fix und Rest einzeln (die Regel «jeder Teil ein PR» gilt für Mein Tag, nicht hier) |
| 5 PR-Nummer | **a** bei jeder Neuheit klein sichtbar | «PR 1820» in Karte, Fenster und Liste, suchbar |

Verworfen: eigene Kommentarfunktion zu einem Release (Warteliste, «Klappt nicht» mit Satz im Logbuch genügt vorerst); Umbruch-Fix als eigener kleiner PR (Noah wollte ein Paket).
