# Dauer nachtragen für Tourtage

21.11.2026 · Auftrag: Noah 22:47 (Karte «Tourtage ohne Strava-Zeit», Thread «Auswertung über alle Sportarten verbessern»)

- Reine Tourtage ohne Strava-Aktivität und ohne Haken mit Minuten bekommen keine geschätzte Zeit (bis dahin 0 Stunden). Sie stehen in «Dauer nachtragen» als «Tour am …, wie lange?»; der Tipp schreibt die Dauer und sie zählt als gemessen.
