# Packen: Taschen auf kleinen Handys in zwei Spalten

PR #? · 28.10.2026 · Auftrag: Noah, Screenshot der offenen Issues (Thread «Offene GitHub-Issues prüfen»)

## Was ist neu
- Auf sehr schmalen Handys (320 px breit) stehen die Taschen-Kacheln unter Packen zu zweit statt zu dritt.
  Vorher wurde «Oberrohrtasche» oder «Rahmentasche» mitten im Wort getrennt und «12 Teile · 2.5 kg mit Essen»
  abgeschnitten. Das war der rote Test in der vollen Prüfung (Issue #354, seit #341 «Taschen mit Ringen»).
- Ab 360 px (z. B. Samsung A56) bleibt alles wie bisher: drei Kacheln pro Zeile.

## Was fällt weg oder rutscht tiefer
- nichts. Auf 320 px braucht die Taschenliste eine Zeile mehr.

## Selbst entschieden
- Zwei Spalten statt kleinerer Schrift, damit die Namen lesbar bleiben.

- keine

## Stand im Plan (roadmap.md / vorhaben.md)
- unverändert

## Prüfschritte (nach dem Merge auf der echten Seite)
1. Am Computer in Chrome: Tour öffnen › Packen, mit F12 die Handy-Ansicht auf 320 px stellen.
2. Die Taschen stehen zu zweit, kein Name ist mitten im Wort getrennt.
3. Auf deinem Handy (A56) sieht Packen gleich aus wie vorher.
