# Ziel-Kasten einklappen

PR (diese Änderung) · 28.10.2026 · Auftrag: Noah «a ★ Einklappen, Beenden extra» (Thread «Live Navigation»)

## Was ist neu
- Das X am Kasten «Zu …» / «Umweg zu …» klappt ihn auf eine Zeile zu (Name, km, Ankunft). Antippen öffnet ihn wieder. Eingeklappt bleibt eingeklappt, auch nach dem Neuladen.
- Neuer Knopf «Navigation beenden» im offenen Kasten, mit Rückgängig.

## Was fällt weg oder rutscht tiefer
- Das X beendet die Navigation nicht mehr (alt: X → Navigation weg; neu: Kasten öffnen › «Navigation beenden»).

## Selbst entschieden
- Fragt die App etwas (Rückweg am Ziel, automatisch neu geplanter Rückweg), bleibt der Kasten offen, damit die Frage sichtbar ist.
