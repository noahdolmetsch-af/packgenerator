# Fahrt läuft nach dem Neuladen weiter

PR (diese Änderung) · 28.10.2026 · Auftrag: Noah, Handy-Test 28.10 («bin auf dieser seite gelandet», Thread «Live Navigation»)

## Was ist neu
- Lädt die App mitten in einer Fahrt neu, geht die Fahrt bis 3 Stunden nach dem letzten GPS-Punkt von selbst weiter (vorher 20 Minuten). Bei einem Halt mit Bildschirm aus kommt kein neuer Punkt, darum fiel Noah nach dem Neuladen auf die Startseite mit «Fahrt von 14:57 weiterführen».

## Was fällt weg oder rutscht tiefer
- nichts. Ist die Fahrt älter als 3 Stunden, bleibt der Knopf «Fahrt von … weiterführen» wie bisher.

## Selbst entschieden
- 3 Stunden: lang genug für eine Pause im Café, kurz genug, dass eine vergessene Fahrt vom Vortag nicht von selbst weiterläuft.
