# Eigener Link

PR · 01.11.2026 · Auftrag: Noah «4a» (Thread «Umfrage-Antworten in der App ansehen»)

## Was ist neu
- Öffnest du auf dem Gerät, auf dem du die Frage gemacht hast, den Antwort-Link, steht oben «Das ist deine eigene Frage. Zu den Antworten». Der Link führt zur Ergebnisseite. Gilt für alle Mini-Tools (Termin, Umfrage, Anmeldeliste, Einladung, Essen).
- Die Antwortseite bleibt wie sie ist; du kannst weiter selbst antworten.

## Was fällt weg oder rutscht tiefer
- nichts.

## Selbst entschieden
- Erkannt wird die eigene Frage an der Server-Nummer in db.settings «mini-tools» (nur auf diesem Gerät). Auf einem anderen Gerät erscheint der Hinweis nicht.

## Stand im Plan
- Ergebnisseite Termin finden: Schritt 4 von 5.

## Prüfschritte (nach dem Merge auf der echten Seite)
1. Eine Mini-Tools-Frage machen, ihren Link im selben Browser in einem neuen Tab öffnen: oben der Hinweis.
2. «Zu den Antworten» tippen: die Ergebnisseite öffnet.
