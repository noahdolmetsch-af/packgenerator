# Tourenvorschläge: Art, Start und Zeilen

Auftrag: Noah «mit 1 beginnen, dann 2-5» (Thread «Planen: Mountainbike-Tourenvorschläge aus offenen Daten»)

## Was ist neu
- Filter «Tourart»: Singletrail (ab 40 % Singletrail), Abfahrt, Schotter und Wege (ab 40 % ungeteert, ohne Abfahrt), Runde. Eine Tour kann mehrere Arten haben; ein Tipp auf mehrere Arten zeigt Touren, die eine davon haben. Arten ohne Tour erscheinen nicht. Die Karten zeigen die Arten als kleine Marken.
- Filter «Start»: bis 30, 60 oder 100 km vom Wohnort zum Start (Luftlinie). Ohne Wohnort steht ein Hinweis, und der Filter wirkt nicht.
- «Zeilen wählen» unter «Warum dieser Vorschlag?»: Zeit, Schnee, Schwierigkeit, neu für dich und Abstand lassen sich einzeln ausblenden (bleibt auf dem Gerät).

- Kein neuer Katalogeintrag: der Filter gehört zur Funktion «Tourenvorschläge».
