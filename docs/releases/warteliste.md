# Warteliste

PR · 05.11.2026 · Auftrag: Noah «7a» (Thread «Planen Tennisstunden anbieten bis bezahlen»), Zusatzidee 7

## Was ist neu
- Im Blatt einer vollen Zeit gibt es «Warteliste»: Name und Kontakt eintragen, «Auf die Warteliste setzen». Entfernen jederzeit.
- Wird in dieser Zeit ein Platz frei (Absage), zeigt Heute eine Zeile «Platz frei: … · Mia wartet» mit dem Knopf «Schreiben»; die Nachricht («Ein Platz ist wieder frei …») ist fertig, du sendest sie selbst.
- Im Blatt der Zeit steht dasselbe mit «Schreiben» bei der ersten wartenden Person.
- Die Liste liegt nur auf dem Gerät (Einstellung «booking.waitlist», im Backup).

## Was fällt weg oder rutscht tiefer
- nichts

## Selbst entschieden
- Die Warteliste ist nur Noahs Liste; die Schüler können sich auf der Buchungsseite nicht selbst eintragen (das bräuchte den Server und kommt nur auf Wunsch).
- Nichts wird von selbst gesendet; bucht jemand den freien Platz selbst, verschwindet die Zeile von allein.
