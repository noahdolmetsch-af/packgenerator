# Eine Karte für deine Tour

PR folgt · 19.11.2026 · Auftrag: Noah «1-5a» (Thread «Startseite ruhiger und klarer gestalten»), Entwurf A, Schritt 3 (zweiter Teil)

## Was ist neu
- «Meine Tour» zeigt jetzt, wie weit das Packen ist (Balken, «2 von 6 gepackt», was noch fehlt), das Basisgewicht und einen Link «Packliste ›».

## Was fällt weg oder rutscht tiefer
- Die grosse Tourkarte («Nächste Tour», Zahlenkästen mit Tagen, Stunden, offenen Schritten, Packbalken, Schrittleiste, Knöpfe): sie fällt weg, solange genau eine Tour geplant ist und «Meine Tour» auf Heute steht. Tage und Stunden sagt «Meine Tour» im Zähler oben rechts, die Schritte stehen als vier Phasen darin, «Weiter mit …» ist der eine Hauptknopf.
- Der Hinweis «Auch in Arbeit: n» der grossen Karte fällt mit ihr weg; die Touren stehen weiter unter «Touren».

## Selbst entschieden
- Die grosse Karte bleibt, wenn mehrere Touren geplant sind («Tour 1 von 2»), wenn der Rückblick der Tour offen ist («Wie war …?»), wenn die Tour eine Strecke mit Profil hat oder «Meine Tour» nicht auf der Wand steht. Dort tut sie Dinge, die «Meine Tour» noch nicht kann; ein nächster PR kann sie später auch dort ersetzen.
- Das Basisgewicht und der Packbalken haben nur dann Platz in «Meine Tour», wenn die grosse Karte weg ist; so steht nichts doppelt.
